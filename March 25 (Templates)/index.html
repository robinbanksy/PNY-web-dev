DOM Manipulation with Templates

HTML Template Elements

The HTML Template tag allows us to define HTML structures that we can then clone and insert into the DOM, thus adding dynamically generated elements into our web pages

Templates themselves do not appear in the DOM when the page loads. They are only used as a source for creating new elements.

HTML:

<template id="card-template">
    <div class="card">
        <h3 class="card-title"></h3>
        <p class="card-description"></p>
    </div>
</template>

JS:

// Get the template and the container
const template = document.getElementById('card-template');
const container = document.querySelector('.card-container');

// Clone the template and append it to the container
const clone = template.content.cloneNode(true);
container.appendChild(clone);

The cloneNode method creates a "document fragment", which is like a smaller DOM, independent of the main one. As seen above, it gives us access to methods like querySelector, so we can get access to the elements within the clone.

Since the document fragment is an independent DOM, separate from the main one, we can modify its content without affecting the web page, or the original template.

Once we've modified the clone to our liking, we can append to the main DOM, making it visible on the page. We do this by using the appendChild method on an element in the main DOM which will become the parent of the new element.
