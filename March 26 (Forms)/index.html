Form Data and JSON

Forms

On our web pages, we use input elements to collect data from users. These input elements are often organized into forms, so that related data can be submitted together.

HTML:

<form action="/submit" method="post">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">
    <label for="email">Email:</label>
    <input type="email" id="email" name="email">
    <input type="submit" value="Submit">
</form>

JS:

const form = document.querySelector('form');

form.addEventListener('submit', function(event) {
    // Prevent the default form submission
    event.preventDefault();

    // Get the form data
    const formData = new FormData(form);

    // Convert the form data to JSON
    const jsonData = Object.fromEntries(formData);

    // Do something with the JSON data
    // (e.g., send it to a database or display it on the page)
    console.log(jsonData);
});

JSON

Much of programming, including web development, is centered around the manipulation of data. For example, you may have a database of information which your website draws from, formats, and displays. Or your website might collect data from users with a form like the one above.

There are different methods of storing this data, but one of the most common is called JavaScript Object Notation (JSON). JSON mimics the format of JavaScript objects, making it easy to work with in web applications. However, it is not specific to JavaScript; JSON is used with many different programming languages and use-cases. Its widespread adoption makes it a popular choice for data interchange in web development.

Here's and example of JSON data:

{
    "name": "John Doe",
    "email": "john.doe@example.com"
}

As you can see, it is quite similar to a JavaScript object; it consists of key-value pairs enclosed in curly braces.
